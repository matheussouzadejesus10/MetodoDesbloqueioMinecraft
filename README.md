# Metodo Desbloqueio do Minecraft
Desbloqueio do Minecraft bedrock sem pagar nada(official de matheus souza 10)

[Relembrando] se nao tem certeza que e seguro? pode abrir o arquivo e ler os codigos

## TUTORIAL
1: Baixe o ["Metodo Minecraft Matheus souza 10.zip"](https://github.com/matheussouzadejesus10/MetodoDesbloqueioMinecraft/releases/tag/Releases) em "Releases"

2: Extrair o zip baixado

3"Importante": Instale o "Minecraft For Windows" ou "Minecraft Para Windows"

4: Execute o "instalador.bat"(mas mantenha os arquivos do programa)

5: Aguarde a Instalação terminar, quanto finalizar aperte qualquer botao

6: Pronto E So Jogar :]
